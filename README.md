## Project Idea
حملة صفحة هبوط وقمع تسجيل لسنتر تعليمي للمراجعة النهائية لطلاب الثانوية العامة (اسم السنتر: الدحيح - project 8).

## Work Plan
- **المرحلة الأولى:** تحديد متطلبات الحملة وهيكلة صفحة الهبوط والقمع.
- **المرحلة الثانية:** تصميم واجهة المستخدم وتجربة المستخدم (UI/UX).
- **المرحلة الثالثة:** تطوير برمجيات صفحة الهبوط وربط نموذج التسجيل.
- **المرحلة الرابعة:** الاختبار والمراجعة النهائية والتأكد من استجابة القمع على جميع الأجهزة.

## Roles & Responsibilities
- **فارس محمد هلال:** تخطيط وتنفيذ قمع التسجيل، بناء وتطوير صفحة الهبوط، وإدارة المستودع والملفات.

## KPIs
- نسبة تحويل الزوار إلى طلاب مسجلين (Conversion Rate).
- سرعة تحميل وسلاسة استجابة صفحة الهبوط على الهواتف والأجهزة المختلفة.
- دقة وصحة البيانات المجمعة من خلال نموذج التسجيل.
